## How the entry works

`POST.json` at the repository root names the X post's address. `main.ts`
(Node 22, standard library only) copies `POST.json` into the output
directory — that is all the program does. After the deadline, 27 Nov
2026 18:35 WIB, the house reads the post through FxTwitter and scores
it on `likes + reposts + quotes`. The top 10 split $2 USDC.

Run it locally:

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/POST.json` is then byte for byte this repository's `POST.json`.
